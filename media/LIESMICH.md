# Filme

Jeder Unterordner ist ein Sender. Die Sender werden nach Ordnernamen sortiert,
die Filme darin nach Dateinamen und laufen in Endlosschleife.

```
media/
  01-tagesschau/
    1977-08-01.mp4
    1977-12-31.mp4
  02-hessentag/
    hessentag-dreieich.mp4
  03-testbild/          (leerer Ordner = Testbild)
```

Optionen eines Senders stehen in einer Datei `channel.json` im jeweiligen Ordner,
siehe README im Hauptordner.
